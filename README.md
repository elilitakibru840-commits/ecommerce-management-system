Django E-commerce Platform

A full-stack e-commerce web application built with Django. This project is developed to practice and demonstrate real-world web development concepts, including backend architecture, database design, authentication, APIs, and scalable project structure.

Features

User registration and authentication
Product management
Product categories and brands
Shopping cart system
Order management
Admin dashboard
Product images and media handling
REST API integration

Technologies Used

Python
Django
Django REST Framework
MySQL
HTML, CSS, JavaScript
Git & GitHub

Project Goals

The goal of this project is to build a professional e-commerce system while improving skills in backend development, database design, and full-stack application development.
